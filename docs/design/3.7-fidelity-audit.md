# Design-fidelity audit (slice 3.7, 2026-11-22)

Built screens compared with the approved canvas (v16). The app was captured locally with Playwright at 1440×900 and 390×844, and the admin with a test admin through the browser test suite (`tests/Browser/AuditScreenshotsTest.php`, run with `AUDIT_SCREENSHOTS=1`). The canvas was checked against each artboard's markup, which states sizes, spacing and colours exactly. Screenshots are kept locally and are not in the repo.

Severity: **H** = layout or component differs, **M** = spacing, type or colour differs, **L** = detail.

## What this means for 3.8
Almost every admin deviation comes from Filament's default panel styling rather than per-screen code. The fix is a custom panel theme (sizes, sidebar, cards, tables) plus a shared table configuration (`tabs + filters inline`, row actions, pagination) and a shared edit-page layout, applied to every resource.
